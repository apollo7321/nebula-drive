# Nebula Drive

S3 Client to browse through buckets written in Go with Gio.

## Dependencies

In order to compile you need the following (Debian) packages:

```bash
xorg-dev libwayland-dev libxkbcommon-dev libvulkan-dev libegl1-mesa-dev libgl1-mesa-de libxkbcommon-x11-dev libx11-xcb-dev build-essential
```
